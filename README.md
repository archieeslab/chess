# Offline Chess

Small local 2 player chess game written in C++.

## Build

1. Open `OfflineChess.sln` in Visual Studio 2022.
2. Make sure `Desktop development with C++` is installed.
3. Select `x64`.
4. Build and run.

No extra libraries are required.

## Game

- Local 2 player only.
- Click a piece and then a highlighted legal square.
- Includes check/checkmate, stalemate, castling, en passant and automatic queen promotion.
- New Game resets the board.

## Privacy

The program contains no networking code, telemetry, accounts, cloud features or save files.
